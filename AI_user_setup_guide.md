# AI User Setup Guide

## Core Rule
Do not rely on AI chat memory as the source of truth. Keep your hauling profile and session state in portable JSON files.

## Recommended Files to Keep
- portable_user_profile.json
- latest_hauling_session_state.json
- patch-era telemetry files
- OCR correction files

## Basic Workflow
1. Start a new AI chat.
2. Attach or paste the lightweight operational subset.
3. Attach or paste your portable user profile.
4. Attach or paste latest session state if continuing.
5. Provide screenshots or manual mission entries.
6. Ask for route recommendations.
7. After the session, export updated user profile and session state.

## Provider Neutrality
Use ChatGPT, Claude, Gemini, Copilot, Perplexity, Ollama, LM Studio, or manual copy/paste. No provider is mandatory.
