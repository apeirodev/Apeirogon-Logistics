# Claude Usage Guide

## Recommended Mode
Use project knowledge or file attachments.

## Steps
1. Add the lightweight operational subset as project knowledge or attach files.
2. Attach portable user profile and session state.
3. Provide screenshots or manual mission text.
4. Request structured route outputs.
5. Export updated state at session end.

## Strength
Claude is well suited to long-context documentation and careful operational reasoning.

## Limitation
Claude memory or project context should not replace portable state files.
