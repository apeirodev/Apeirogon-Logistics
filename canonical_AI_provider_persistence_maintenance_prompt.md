# Canonical AI Provider and Persistence Maintenance Prompt

Update the Star Citizen hauling intelligence platform for AI-provider usability and persistent user state.

Objectives:
- add or update AI provider instructions
- preserve provider neutrality
- preserve local-first operation
- preserve manual copy/paste operation
- improve portable user profile and session state workflows
- maintain vendor-memory independence

Tasks:
1. Review provider-specific usage guides.
2. Add new AI providers only as optional provider profiles.
3. Validate portable user profile schema.
4. Validate hauling session state schema.
5. Improve export/import workflows.
6. Update prompt templates.
7. Preserve unresolved values explicitly.
8. Preserve sourced facts, telemetry, OCR, user corrections, heuristics, and runtime values as separate classes.
9. Update README, source registry, changelog, and provider usage profile models.
10. Output package with next three-part version number.

Rules:
- no provider is mandatory
- no AI chat memory is authoritative
- persistent user data must remain portable
- local and manual modes remain first-class
