# Canonical Provider-Neutral Maintenance Prompt

Update the Star Citizen hauling intelligence platform.

Objectives:
- preserve local-first operation
- preserve provider neutrality
- preserve deterministic fallback
- preserve future addon readiness
- preserve privacy-preserving telemetry
- preserve Hull-B Covalex specialization
- preserve generalized hauling support

Tasks:
1. Record current Star Citizen patch version if known.
2. Validate provider contracts.
3. Validate local runtime workflows.
4. Validate deterministic fallback outputs.
5. Validate addon contracts against any newly published official addon capabilities.
6. Ingest new telemetry only as observational data.
7. Update OCR correction rules without inventing missing values.
8. Recalibrate derived heuristics only where evidence supports it.
9. Add new provider adapters as optional modules only.
10. Update ship and issuer models with confidence classification.
11. Update README, source registry, changelog, docs, and manifests.
12. Output an updated package with incremented version.

Rules:
- no provider is mandatory
- addon support is not mandatory
- cloud inference is not mandatory
- OCR is not mandatory
- telemetry contribution is not mandatory
- sourced facts must not be overwritten by heuristics
