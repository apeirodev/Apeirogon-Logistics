# AI Governance Operating Model

## AI Use Cases
- screenshot interpretation
- OCR correction support
- mission extraction
- route recommendation
- telemetry summarization
- documentation assistance

## Controls
- schema validation
- unresolved field preservation
- confidence tagging
- provenance tagging
- human review escalation
- deterministic fallback comparison

## Prohibited AI Behaviour
- inventing mission details
- fabricating telemetry
- assigning exact QT times without runtime data
- inferring unknown ship capabilities
- silently resolving unclear OCR
