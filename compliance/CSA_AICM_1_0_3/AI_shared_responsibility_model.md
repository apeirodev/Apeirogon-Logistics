# AI Shared Responsibility Model

## User
- selects provider
- manages API keys
- verifies AI recommendations
- preserves exported state

## Maintainer
- maintains prompts, schemas, trust boundaries, and provider guidance
- prevents AI output from becoming sourced fact

## AI Provider
- responsible for model service, data handling, retention, and security according to provider terms

## Contributor
- marks telemetry source and confidence
- discloses AI-assisted corrections where relevant

## Platform
- provides schemas, validation rules, deterministic fallback, and governance metadata
