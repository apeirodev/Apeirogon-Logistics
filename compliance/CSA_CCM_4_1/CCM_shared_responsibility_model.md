# CCM Shared Responsibility Model

## Maintainers
- preserve dataset integrity
- manage releases
- maintain schemas
- review contributor submissions
- prevent sourced fact contamination

## Contributors
- submit accurate telemetry
- tag patch versions
- preserve uncertainty
- avoid fabricated values

## Users
- manage API keys
- validate local runtime outputs
- sanitize screenshots
- choose provider privacy posture

## AI Providers
- responsible for their own platform security and data handling according to their terms.

## Project Boundary
Apeirogon Logistics provides operational intelligence structures and guidance. It does not control third-party AI providers, user devices, or Star Citizen client behaviour.
