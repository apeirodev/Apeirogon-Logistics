# Platform Shared Responsibility Model

## Project Maintainers
Maintain schemas, releases, contributor workflows, governance documentation, and trust classification.

## Users
Select providers, manage local state, verify recommendations, and protect API keys.

## Contributors
Submit accurate telemetry, preserve uncertainty, and tag patch version.

## AI Providers
Operate and secure their own services under their own terms.

## Boundaries
The project does not control user endpoints, AI providers, Star Citizen, or future addon APIs.
