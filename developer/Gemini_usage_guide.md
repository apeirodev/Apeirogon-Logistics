# Gemini Usage Guide

## Recommended Mode
Use file upload or context attachment where available.

## Steps
1. Upload the lightweight operational subset.
2. Upload portable user profile.
3. Upload screenshots or paste mission data.
4. Request structured JSON-compatible outputs.
5. Export updated session state.

## Notes
Validate structured outputs carefully and preserve unresolved fields.
