# PRIVACY POLICY

Core principles:
- telemetry contribution is optional
- screenshots remain local unless explicitly exported
- users control their own AI/API keys
- no account linking is required
- no credential collection is performed
- local-first operation is preferred

Users are encouraged to:
- sanitize screenshots before sharing
- avoid uploading personally identifying telemetry
- use local storage for operational history

Telemetry remains observational and contributor-controlled.
