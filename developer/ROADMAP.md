# Roadmap

This roadmap reflects intended future direction only. Nothing here is committed or scheduled.

## Near Term

- real telemetry ingestion from community submissions
- patch recalibration workflow hardening
- OCR engine integration (Tesseract, PaddleOCR, EasyOCR)
- CI/CD hardening and release signing
- contributor telemetry review workflows

## Mid Term

- telemetry-calibrated route scoring
- community telemetry aggregation
- statistically validated heuristics
- local runtime UI (optional, local-only)
- expanded deterministic scoring models

## Long Term

- local runtime IPC and addon contracts (pending official Star Citizen capabilities)
- UI overlay support (optional addon layer)
- governance maturity promotion workflows
- reproducible release infrastructure
- patch-segmented operational modelling

## Permanent Constraints

The following are not on the roadmap and will not be added:

- mandatory cloud services
- provider lock-in
- telemetry-authoritative claims without statistical validation
- certification or compliance claims
- SaaS architecture
- gameplay automation or injection
