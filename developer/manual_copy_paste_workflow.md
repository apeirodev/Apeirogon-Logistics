# Manual Copy/Paste Workflow

## Purpose
Universal mode for users without API keys, local models, or file upload support.

## Steps
1. Open the AI provider of choice.
2. Paste the lightweight prompt.
3. Paste your portable user profile.
4. Paste latest session state if available.
5. Manually transcribe mission data or paste OCR output.
6. Ask for route recommendation.
7. Copy the exported updated JSON state at the end.

## Rule
Manual mode is first-class and must remain supported.
