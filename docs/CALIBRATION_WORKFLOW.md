# Calibration Workflow

1. Segment telemetry by patch era.
2. Exclude unverified OCR values from high-confidence calibration.
3. Compare observed vs predicted route burden.
4. Recalibrate derived heuristics only.
5. Preserve sourced facts unchanged.
6. Record recalibration trigger and sample size.
7. Archive stale telemetry instead of deleting it.
