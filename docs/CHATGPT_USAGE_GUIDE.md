# ChatGPT Usage Guide

## Recommended Mode
Use a project or chat with file attachments.

## Steps
1. Attach the lightweight operational subset.
2. Attach your portable user profile JSON.
3. Attach latest hauling session state if continuing.
4. Upload screenshots or paste extracted mission data.
5. Ask for route recommendation using the prompt library.
6. At the end, ask ChatGPT to export updated profile and session state JSON.

## Do Not
- rely on ChatGPT memory as authoritative
- allow unresolved OCR values to be guessed
- overwrite sourced facts with telemetry
