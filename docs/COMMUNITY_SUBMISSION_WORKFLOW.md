# Community Submission Workflow

1. Open an issue or pull request.
2. Identify submission type: telemetry, source update, OCR correction, patch validation, documentation, schema improvement.
3. Include patch version.
4. Include evidence where available.
5. Mark unresolved values explicitly.
6. Maintainers classify submission confidence.
7. Accepted submissions update sourced data, telemetry cohorts, or derived heuristics as appropriate.
