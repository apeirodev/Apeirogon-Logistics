# Final Patch Maintenance Workflow

1. Record patch version.
2. Validate core hauling mechanics.
3. Validate cargo and freight elevator behaviour.
4. Validate OCR UI changes.
5. Run known baseline routes.
6. Compare telemetry against prior patch era.
7. Mark stale heuristics.
8. Segment telemetry by patch.
9. Recalibrate only derived heuristics.
10. Update source registry and changelog.
