# Getting Started

1. Read `final_operational_playbook.md`.
2. Use the lightweight operational manifest for daily route analysis.
3. Submit screenshots for OCR-based mission extraction.
4. Preserve unresolved values.
5. Use telemetry templates after each hauling session.
6. Tag all telemetry by patch version.

Primary workflow:
- screenshot in
- mission extraction
- route recommendation
- session execution
- telemetry logging
- patch-aware recalibration
