# How to Avoid Bad AI Recommendations

## Reject Recommendations That
- invent unreadable mission values
- assume exact QT time without runtime data
- ignore cargo fragmentation
- exceed practical unloading complexity
- mix sourced facts with telemetry
- rely on old patch-era assumptions
- ignore unresolved OCR fields
- treat vendor memory as authoritative

## Always Require
- confidence notes
- unresolved field list
- accepted and rejected mission rationale
- route risks
- patch version when known
