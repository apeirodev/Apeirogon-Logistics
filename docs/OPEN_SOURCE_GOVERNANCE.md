# Open Source Governance

## Maintainer Responsibilities
- Preserve source vs heuristic separation.
- Reject invented or unsupported claims.
- Maintain patch-era segmentation.
- Review telemetry confidence.
- Preserve public contributor clarity.

## Source Trust Policy
Preferred order:
1. Official source
2. Current verified game observation
3. Multiple independent community observations
4. Single contributor telemetry
5. Derived heuristic

## Telemetry Privacy
- Do not require player identity.
- Avoid collecting irrelevant screenshots.
- Do not collect credentials, private chats, or account data.
