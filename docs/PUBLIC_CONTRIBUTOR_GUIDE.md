# Public Contributor Guide

## Purpose
This project provides structured operational data and prompts for Star Citizen hauling route analysis.

## What Contributors Can Submit
- verified hauling telemetry
- OCR correction examples
- patch validation notes
- issuer behaviour observations
- ship operational observations
- route-distance enrichment proposals
- documentation improvements

## Contribution Rules
- Do not invent values.
- Mark unknowns as unresolved.
- Include patch version wherever possible.
- Separate observed telemetry from interpretation.
- Avoid personal or account-identifying information.
- Submit screenshots only when they support the specific operational claim.

## Review Principles
- Sourced facts require citation.
- Telemetry requires patch tagging.
- Heuristics require clear classification.
- Operational doctrine changes require discussion.
