# Route Analysis Handbook

## Core Outputs
- accepted missions
- rejected missions with reasons
- SCU by pickup
- SCU by destination
- ordered route
- operational risks
- unresolved OCR values

## General Strategy
Prioritize:
1. same-pickup stacking
2. destination overlap
3. low fragmentation
4. manageable unloading
5. low dead-leg risk
6. route sustainability
