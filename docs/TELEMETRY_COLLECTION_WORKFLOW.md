# Recommended Telemetry Collection Workflow

1. Capture screenshots before accepting missions.
2. Record accepted and rejected missions.
3. Note actual start and completion times.
4. Record unloading duration by destination.
5. Record freight elevator delays and failures.
6. Record dead-leg outcomes.
7. Record reroute causes.
8. Record whether the route preserved an orbital loop.
9. Mark OCR fields as verified only when visually confirmed.
10. Use observed outcomes to refine derived heuristics only.
