# Recommended Minimum Telemetry Sample Sizes

## Preliminary Heuristic Tuning
- 10-20 hauling sessions
- 50+ missions

## Moderate Confidence Calibration
- 25-50 hauling sessions
- 150+ missions

## High Confidence Operational Calibration
- 75+ hauling sessions
- 500+ missions

## Freight Elevator Penalty Calibration
- 100+ unloading events

## Orbital Loop Persistence Calibration
- 50+ observed mission chains

## Dead-Leg Risk Calibration
- 100+ observed route chains

## Notes
- Sample quality matters more than raw quantity.
- Patch changes invalidate older telemetry confidence.
- Mixed server conditions should be preserved, not normalized away.
