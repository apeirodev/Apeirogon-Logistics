# Canonical Public Maintenance Prompt

Update the public Star Citizen hauling intelligence platform.

Objectives:
- preserve source vs heuristic separation
- preserve telemetry as observational
- preserve OCR uncertainty
- preserve runtime-derived values
- preserve Hull-B Covalex specialization
- preserve generalized hauling support
- maintain public contributor clarity

Tasks:
1. Record Star Citizen patch version.
2. Ingest contributor submissions.
3. Validate source trust.
4. Segment telemetry by patch era.
5. Reconcile validation references.
6. Update OCR corrections.
7. Recalibrate derived heuristics only from verified telemetry.
8. Refine operational doctrine only through explicit review.
9. Add or update ship and issuer profiles only with confidence classification.
10. Update README, changelog, source registry, manifests, and public docs.
11. Output an updated public package with incremented version.

Rules:
- do not invent mission details
- do not infer unknown ship capabilities
- do not overwrite sourced facts with telemetry
- do not blend incompatible patch-era telemetry
- do not treat heuristics as facts
